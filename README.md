
# MAZEN AI — Frontend Application

MAZEN AI is a modern, responsive single-page web application built to provide an interactive AI chat and voice assistant experience. It uses React 18, TypeScript, and Vite, featuring dynamic persona switching, advanced prompt configuration, and multilingual voice control options.

---

## Core Features

- **Personas and Model Controls:** Switch between custom assistant roles and adjust response modes based on the specific task.
- **Bilingual Voice Interaction:** Speech-to-text and text-to-speech audio interface supporting both Arabic and English.
- **Quick Actions:** Built-in shortcuts for code generation, analysis, summarization, translation, and idea generation.
- **Advanced Prompt Tuning:** Fine-tuning parameters including system prompts, context constraints, temperature, and token limits.
- **Modern Responsive UI:** Clean design with dark and light modes, smooth interface transitions, and clear typography.

---

## Tech Stack

- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations and Icons:** Framer Motion, Lucide React
- **Package Manager:** Bun / npm
